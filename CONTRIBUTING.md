# Contributing to LibrePods

Thanks for your interest in contributing!

## Getting Started

1. Fork the repository and clone your fork.
2. Run `python3 setup_validator.py` to verify your environment is compatible.
3. Install dependencies: `pip install -r requirements.txt`
4. Make your changes on a feature branch and open a pull request.

## Code Style

- PEP 8, max line length 100.
- Add docstrings to public functions.
- Run `python3 -m flake8 .` before submitting.

## Reporting Issues

Please include your platform info (OS, Python version, BlueZ version) when filing bugs.
The output of `python3 setup_validator.py` is helpful for diagnosis.
